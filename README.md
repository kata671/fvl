# Fractal Vibration Lab — FAEM

**https://fractalvibrationlab.com**

Fractal Acoustic–Energy Mapping: nodal domain scaling on Chladni plates, open tools.

## Highlight

On 8 real square-plate photos (155–6800 Hz):

**N_domains ∝ f^{0.521 ± 0.054}** · R² = 0.94  

Classical Chladni / Rayleigh expectation: **0.5**

## Deploy (GitHub Pages)

1. Create a new repository
2. Upload **all files from this folder to the repo root** (not inside a subfolder)
3. Settings → Pages → Source: Deploy from branch `main` → folder `/ (root)`
4. Point domain `fractalvibrationlab.com` to GitHub Pages (or use `username.github.io/repo`)
